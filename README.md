# 青禾 · 图书馆学习空间助手

《开源 AI 技术实践》期末项目，路径 A。面向需要自习或开展小组讨论的学生，将人数、用途转成带资料编号的地点建议和预约说明。演示资料是虚构的，不代表任何学校的真实政策、开放时间或空位。

## 助手工作台

- **时段总览**。查看场地、可约时段和当前浏览器的预约数量。日程支持按用途筛选、仅看有空位，点击可约格子会进入场地筛选。
- **查找场地**。按人数、用途、时段比较容量和位置，确认模拟预约。当前时段满位时可跳到推荐时段。
- **智能问答**。先问“想找个学习空间”，再补充“4 人下午讨论”，即可查看时段空位和工具记录。
- **我的预约**。支持刷新后查看、改期、取消和 CSV 导出。目标时段已占用时，原预约保留。
- **使用规则**。独立浏览开放时间和预约规则，可用资料编号和问答结果相互核对。

演示日有 09:00、14:00、19:00 三个一小时时段。数据为本机模拟，预约存入被 Git 忽略的 SQLite 文件。汇报材料作为独立文件打开。

场地日程与资源筛选参考 [Booked Scheduler](https://github.com/JohanManders/BookedScheduler)，预约管理的设计参考 [Cal.diy 功能文档](https://github.com/calcom/cal.diy/blob/main/apps/docs/content/index.mdx)。本项目自行实现这些交互。

## 在 Windows 复现

需要 Python 3.10 或以上、Edge 或 Chrome；程序只用标准库。双击 `启动演示.cmd`，或在仓库目录执行：

```powershell
python app.py
```

保持终端开着，打开 http://127.0.0.1:8765/。默认使用无需联网的离线规则演练。用 Ctrl+C 停止服务。如果端口冲突，可执行 `python app.py --port 8766` 并访问对应端口。幻灯片 `slides.html` 可单独双击打开，左右方向键翻页。

### 启用模型驱动模式

```powershell
Copy-Item .env.example .env
notepad .env
python app.py
```

填入可用的 `OPENAI_API_KEY`。默认走 OpenAI API，模型为 `gpt-4.1-mini`；也可改为提供商账号有权限、支持 Chat Completions 工具调用的模型和可信兼容地址。配置后重启，网页选择「在线智能体」。课前务必现场网络试跑一次；接口报错时切回离线演练。在线模式会把问题与工具返回发送给配置的模型服务，请只使用示例或不含隐私的文本。密钥只放本机，不提交 Git、不放在幻灯片、不展示终端配置。

## 技术与目录

- `app.py` / `demo.html`：本地 HTTP 与浏览器界面，显示结果和工具记录。
- `agent.py`：自写 Agent 循环（未依赖框架）。模型选工具，程序按白名单验证并执行，用对应调用 ID 回传结果，最多六轮请求。
- `data.json`：三条模拟场地、两条规则。三个业务工具分别筛场地、查时段空位、查规则；技能工具按需读取说明。
- `skills/study-space-plan/SKILL.md`：推荐场景的筛选步骤、异常分支和引用格式，在线调用时内容真实回传模型。
- `slides.html` / `汇报与提交.md`：8 页 HTML 课件、逐页讲稿、操作顺序、答辩和提交清单。
- `demo-evidence.json`：本地运行记录，记录模式、问例、回答和工具结果。

## 课堂验收问例

| 输入 | 离线预期 | 可核对的证据 |
| --- | --- | --- |
| 4 人讨论，需要预约吗？ | 青禾研讨室、需预约 | S01 / P01；3 次工具调用 |
| 2 人安静自习，有推荐吗？ | 静读区、无需预约 | S03 / P01；讨论参数为 false |
| 12 人小组讨论，有合适地点吗？ | 无匹配，建议拆分 | 场地工具返回空数组 |
| 图书馆几点开放？ | 08:00–22:00 | P02；仅查规则 |
| 想找个学习空间。 | 询问人数和用途 | 不发出工具调用 |

在线表述和调用顺序可能因模型而异，需检查推荐是否有工具依据。离线模式为确定规则，支持上述问例和同类输入，不能理解任意改写。
