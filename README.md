# 青禾 · 图书馆学习空间助手

《开源 AI 技术实践》期末项目，路径 A。面向需要自习或开展小组讨论的学生，将人数、用途转成带资料编号的地点建议和预约说明。演示资料是虚构的，不代表任何学校的真实政策、开放时间或空位。

[期末汇报 PPT](青禾期末汇报.pptx) · [现场演示台本](日期与馆藏演示台本.md)

## 助手工作台

- **时段总览**。查看场地、可约时段和当前浏览器的预约数量。日程支持按用途筛选、仅看有空位，点击可约格子会进入场地筛选。
- **查找场地**。按日期、人数、用途和时段比较位置、容量与设备，确认模拟预约。当前时段满位时可跳到推荐时段。
- **智能问答**。先问“想找个学习空间”，再补充“4 人下午讨论”，即可查看时段空位和工具记录。
- **我的预约**。支持刷新后查看、改期、取消和 CSV 导出。目标时段已占用时，原预约保留。已被其他会话预约的时段可排队，空位释放后按顺序自动转正。也可模拟签到、结束使用和退出候补。
- **使用记录**。查看预约、改期、取消、候补转正、签到和结束使用的时间线。
- **设备和占用查询**。问“哪些场地有投影”或“哪个时段最空”，可查阅工具结果。总览统计演示日时段占用率。
- **馆藏检索与阅读清单**。按关键词或 13 个主题浏览 24 本样例资料、架位和状态，收藏保存在当前浏览器。
- **学习计划**。填写主题、学习目标、基础、总时间、学习次数和个人重点。可选择阅读理解、考试复习、项目产出或技能练习。工作台按规则分配任务和时长，并推荐匹配的样例馆藏。可以添加、删除、编辑任务，勾选完成并查看总时长是否超出预算。修改保存在当前浏览器。
- **使用规则**。独立浏览开放时间和预约规则，可用资料编号和问答结果相互核对。

支持按日期查看与预约 09:00–10:00、14:00–15:00、19:00–20:00。改期可同时更改日期和时段，候补按同一天、同一场地和时段排队。旧版无日期的记录首次启动会归到迁移当天（上海时间）。数据为本机模拟，预约存入被 Git 忽略的 SQLite 文件。汇报材料作为独立文件打开。

场地日程与资源筛选参考 [Booked Scheduler](https://github.com/JohanManders/BookedScheduler)，预约管理的设计参考 [Cal.diy 功能文档](https://github.com/calcom/cal.diy/blob/main/apps/docs/content/index.mdx)。候补、签到和操作记录参考 [LibreBooking](https://github.com/LibreBooking/librebooking/blob/develop/docs/source/INSTALLATION.rst) 与 [Resource Reserver](https://github.com/sylvester-francis/Resource-Reserver)。馆藏的关键词检索、架位与状态展示参考 [Open Library](https://github.com/internetarchive/openlibrary) 和 [Koha](https://github.com/Koha-Community/kohadocs/blob/master/source/circulation.rst)。本项目自行实现交互，馆藏和场地均为本地样例。

## 在 Windows 复现

需要 Python 3.10 或以上、Edge 或 Chrome；程序只用标准库。双击 `启动演示.cmd`，或在仓库目录执行：

```powershell
python app.py
```

保持终端开着，打开 http://127.0.0.1:8765/。默认使用无需联网的离线规则演练。用 Ctrl+C 停止服务。如果端口冲突，可执行 `python app.py --port 8766` 并访问对应端口。幻灯片 `slides.html` 可单独双击打开，左右方向键翻页。

### 启用模型驱动模式

```powershell
Copy-Item .env.example .env
notepad .env
python app.py
```

填入可用的 `OPENAI_API_KEY`。默认走 OpenAI API，模型为 `gpt-4.1-mini`；也可改为提供商账号有权限、支持 Chat Completions 工具调用的模型和可信兼容地址。配置后重启，网页选择「在线智能体」。课前务必现场网络试跑一次；接口报错时切回离线演练。在线模式会把问题与工具返回发送给配置的模型服务，请只使用示例或不含隐私的文本。密钥只放本机，不提交 Git、不放在幻灯片、不展示终端配置。

## 技术与目录

- `app.py` / `demo.html`：本地 HTTP 与浏览器界面，显示结果和工具记录。
- `agent.py`：自写 Agent 循环（未依赖框架）。模型选工具，程序按白名单验证并执行，用对应调用 ID 回传结果，最多六轮请求。
- `data.json` 保存模拟场地、设备和使用规则。
- `planner.py` 管理日程、预约、候补、签到与操作记录。
- `library.py` 和 `catalog-extra.json` 提供馆藏检索和个性化学习计划。
- `skills/study-space-plan/SKILL.md`：推荐场景的筛选步骤、异常分支和引用格式，在线调用时内容真实回传模型。
- `slides.html` / `汇报与提交.md`：8 页 HTML 课件、逐页讲稿、操作顺序、答辩和提交清单。
- `demo-evidence.json`：本地运行记录，记录模式、问例、回答和工具结果。

## 课堂验收问例

1. 选择明天，预约松风研讨室 14:00。切换到后天，确认同一场地的 14:00 仍可预约。
2. 问「明天 4 人下午讨论」，展开工具调用记录，核对日期、人数与场地状态。
3. 在馆藏检索选择「数学」，查看《线性代数练习手册》的架位和状态，并收藏到阅读清单。
4. 在学习计划输入「线性代数」、考试复习、45 分钟和「矩阵运算」，生成后自行添加任务并勾选完成。

在线表述和调用顺序可能因模型而异，需检查推荐是否有工具依据。离线模式为确定规则，支持上述问例和同类输入，不能理解任意改写。
